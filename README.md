## 🔨 What I'm Building

### 🔒 FitLock

**FitLock** is an Android app that makes you exercise before you can use distracting apps. 💪📱

The idea is simple: instead of just blocking an app, you complete a small workout to earn access.

Built with:

* Kotlin
* Jetpack Compose
* Android
* Coroutines
* Camera / pose detection
* GitHub Actions
